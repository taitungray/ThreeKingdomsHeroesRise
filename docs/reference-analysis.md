# 三國：群英再起參考遊戲分析

本文件只整理公開資訊與可轉化的設計觀察，不複製《도원결의：방치형 삼국지》的素材、文字、角色圖、商標或程式碼。

## 研究來源

- [Google Play 商店頁面](https://play.google.com/store/apps/details?id=com.codetiger.threekingdom)（2026-08-26 查閱）
- 商店頁面公開的 About this game、分類、截圖入口與官方社群連結

Google Play 公開介紹將它定位為像素風 Three Kingdoms RPG／Idle RPG，重點包含武將組合、戰術配置、陣營戰鬥、離線成長，以及步兵、弓兵、騎兵、謀士等定位。介紹也特別強調不用抽卡即可自由組合武將，組合與站位比單純收集更重要。

## 可借鑑的產品結構

| 面向 | 公開觀察 | 本專案採用的自主方案 |
| --- | --- | --- |
| 核心幻想 | 像素三國、武將組合、戰術與放置成長 | 以「軍帳中派兵、推進戰役、看武將發揮」為核心幻想 |
| 核心循環 | 組隊 → 戰鬥 → 成長 → 再組隊；離線也會成長 | 征戰畫面持續自動戰鬥，結算銅錢／糧草／經驗，回到武將與編隊面板做決策 |
| 武將 | 不同武將有獨特能力，組合比純稀有度重要 | 每位武將有陣營、兵種、品質、技能、被動數值與紙娃娃裝備 |
| 兵種 | 步兵、弓兵、騎兵、謀士形成戰術差異 | 以射程、攻速、防禦、技能範圍和站位加成落實差異 |
| 戰術 | 站位與戰術配置會改變戰鬥結果 | 軍令提供前排耐久、中排輸出、後排速度／射程的取捨 |
| 放置 | 離線後仍累積收益 | 以最後存檔時間計算，最多累積 8 小時，登入後顯示可領取獎勵 |
| 故事 | 黃巾、桃園結義與群雄崛起等歷史節點 | 以章節／關卡資料表承載，不把每一關寫成獨立程式 |
| 付費／廣告 | 商店頁顯示有內購與隨機物品標示 | 本專案先以可選獎勵廣告與非阻斷式放置循環為主，正式 ID 只由發布設定注入 |

## 20 個功能觀察轉成規格

1. 核心玩法：短時間可看見戰鬥回饋，長時間靠放置收益持續成長。
2. 主畫面：戰鬥、資源、關卡、速度與自動狀態必須一眼可見。
3. 戰鬥畫面：友軍／敵軍、血條、傷害數字、技能特效和波次狀態形成即時回饋。
4. 武將系統：卡片可進入詳情，詳情能看到角色特色與可用操作。
5. 武將養成：升級要消耗資源並反映在戰力與實戰數值。
6. 編隊系統：可上陣、下陣、替換和保存位置。
7. 兵種系統：至少要改變射程、攻速、耐久或技能形狀，而不是只換標籤。
8. 技能系統：普通攻擊累積技能計數，技能有獨立冷卻與角色差異。
9. 戰鬥流程：進場、接近、普通攻擊、技能、死亡、波次清除、Boss、結算。
10. 關卡系統：章節資料包含場景、Boss、敵人組合、倍率與獎勵。
11. 推圖流程：通關開啟下一關，已通關關卡可以重打。
12. 放置收益：戰鬥外也能依進度產生銅錢與糧草。
13. 離線收益：以 `lastSeen` 與上限計算，必須明確顯示時間與可領取數量。
14. 資源循環：銅錢升級武將，糧草升級戰術，玉符作為稀有通關獎勵。
15. 任務系統：成就以關卡、武將數和總等級做長期目標。
16. 成長節奏：前幾關快速解鎖武將，中期靠兵種與站位做決策。
17. UI 結構：底部主導航、右側輔助功能、面板詳情和戰場 HUD 分層。
18. 玩家操作流程：進入即有可玩的自動戰鬥，非戰鬥操作都能在 1～2 次點擊內完成。
19. 數值成長：關卡倍率、英雄等級、裝備、軍令共同構成戰力，避免只靠單一數值。
20. 結果與獎勵：普通波次即時給小獎勵，Boss 給明確結算、解鎖與下一關提示。

## 不確定處的自主決策

公開頁面沒有提供內部傷害公式、完整關卡表、技能冷卻或離線上限，因此本專案採用可調整的資料驅動規格：

- 傷害：攻擊 × 技能倍率 − 防禦減免，再加入小幅隨機浮動與暴擊。
- 難度：章節與關卡倍率遞增，普通波次與 Boss 使用不同生命／攻擊係數。
- 離線：最多 8 小時，收益與目前進度正相關，但不讓離線收益取代戰鬥決策。
- 編隊：前排偏耐久、中排偏輸出、後排偏射程與速度；站位要能實際改變戰鬥。
