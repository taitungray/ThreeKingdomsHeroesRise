# 三國：群英再起目前遊戲規格

狀態：CURRENT。更新日期：2026-08-28。本文件只描述目前可由程式、資料、manifest 或測試核對的事實；規範、待辦、問題細節與歷史方案各自放在對應目錄。

## 產品與核心循環

- `已確認`：直式 Web/H5 三國放置 RPG。
- `已確認`：核心循環為訪客／登入 → 配置武將與裝備 → 自動戰鬥 → 三個普通波次 → Boss → 結算資源與關卡 → 成長後再戰。
- `已確認`：資料目前包含 50 名武將、20 章／100 關、普通敵人池、每波敵將與 Boss 敵將。
- `已確認`：50 名武將目前主要共用 12 組 `visual` 行為模板；完整 `skillSpecs` 只有 12 組，其餘角色詳情使用通用 fallback。
- `已確認`：關卡名稱由循環前綴產生，並非逐關依章節／敵人策劃；章名與首關名存在語意錯配。

## 主畫面與操作

- `已確認`：主畫面包含頂部主公、速度、關卡資訊，右側四個快捷與更多抽屜，Canvas 戰場，資源／首領列，以及五個底部頁籤。
- `已確認`：戰鬥支援自動進行、速度切換、波次、Boss、勝敗結算與重試／下一關路徑。
- `已確認`：專案目前沒有 `navigator.vibrate` 呼叫。
- `已確認`：技能觸發會呼叫大型底部對話；自動推關進入 `startStage()` 時會關閉目前面板。
- `已確認`：訪客設定頁目前讀取不存在的 `username` 欄位，實際資料使用 `displayName`。

## Runtime 與戰鬥渲染

- `已確認`：載入順序為 audio → data（game-data, hero-biographies, battle-quotes, shop-data）→ core → combat → render → UI（base, heroes, modes, panels）→ cloud-save → main；`game.js` 只保留相容性標記。
- `已確認`：CSS 採模組化拆分架構（`css/base.css`、`css/hud.css`、`css/avatars.css`、`css/panels.css`），由 `styles.css` 統一匯總，兼顧開發維護性與發布建置效能。
- `已確認`：單位狀態包含移動、攻擊 action、受擊、死亡、技能、波次與結算資料。
- `已確認`：角色 body、portrait、attack、mount、Boss、VFX、terrain 與 combat weapon 有 WebP／manifest 管理，Canvas 使用 nearest-neighbor。
- `已確認`：Canvas transform 洩漏已修正，source 與同步後 `www` 的真實 Chrome transform gate 通過。
- `已確認`：攻擊圖集目前未通過 body coverage gate，renderer 以 `ATTACK_SPRITES_APPROVED = false` 隔離，暫時使用 body、action transform 與外部兵器路徑。
- `已確認`：7 個 Boss 身分目前映射到 4 張 Boss sprite；普通敵人、敵將與 Boss 大量使用其他武將 body alias。
- `已確認`：戰場兵器有 9 個基礎資產，額外武器 ID 大量 alias 到通用資產，握點主要依武器類型共用而非逐角色／方向定義。
- `已確認`：renderer 仍保留程序 body／mount fallback；依現行戰鬥渲染契約不可作為正式資產。
- `不一致`：UI 動作規範禁止全畫面震動，但 runtime 仍保留 shake 路徑。

## 成長、內容與面板

- `已確認`：編隊支援 3×3 換位操作與前後排站位加成（前排堅壁、中排突擊、後排策應），並即時計算啟動之武將羈絆。
- `已確認`：戰法改為每場攜帶 1 個出戰生效，支援策略性切換與升級。
- `已確認`：裝備以玩家擁有清單為限進行換裝與比較；問天樓、演武場與日常副本全部接通正式戰鬥與結算流程。
- `已確認`：戰令（征戰敕令）具備 1~30 階等級晉升與獎勵領取系統；全週期經濟數值模擬腳本（`npm run test:economy`）驗證 1~100 關產銷平衡。
- `已確認`：離線掛機（AFK）具備專屬征戰回歸結算面板，支援名將碎片、玉璧與資源一鍵/雙倍入庫；戰鬥結算具備 MVP 傷害高亮標記。
- `已確認`：戰鬥支援名將怒氣大招立繪奧義特寫（Skill Cut-in）、暴擊與「斬/破敵」打擊浮字、頂部動態主線目標指引（Quest Tracker）與武將詳情緣分圖譜。
- `已確認`：戰鬥全面接入實體 WAV 音效：無雙大招觸發專屬奧義音效、暴擊觸發加重打擊音效、Boss 破敵觸發震撼音效。
- `已確認`：圖鑑實裝四大勢力（蜀漢/曹魏/東吳/群雄）名將收集共鳴里程碑（3/6/10 人）與玉璧獎勵；戰鬥支援名將與 Boss 專屬動態像素喊話氣泡。
- `已確認`：武將詳情頁實裝全 50 位名將正史《三國志》與《演義》生平列傳卡片（字號、籍貫、生平事蹟、傳奇功績典故）。
- `已確認`：實裝四大兵種動態相剋機制（步克弓、弓克騎、騎克步、謀士法攻）與「兵法精研」（Lv.1~10）屬性養成；戰鬥畫面支援 20 大章動態戰場天氣環境粒子（細雨、飛雪、赤壁烈火微粒、黃沙風暴、秋風落葉與天命金光）。
- `已確認`：實裝名將「專屬神兵真名共鳴」系統（關羽·真青龍偃月、張飛·真丈八蛇矛、趙雲·真龍膽亮銀、諸葛亮·真羽扇綸巾、呂布·真方天畫戟、劉備·真雌雄雙股等），裝備專屬神兵即時啟動獨立特權與金色光輝標籤。
- `已確認`：實裝「名將傳奇列傳試煉」（Hero Fate Trials，關羽·千里走單騎、趙雲·長坂坡百人斬、諸葛亮·七星壇借東風、曹操·官渡奇襲烏巢、呂布·虎牢關戰三英、周瑜·赤壁烈火燎原），獨立戰鬥模式，通關解鎖專屬動態頭像框、稱號、大量名將碎片與玉璧。

## 存檔、離線與雲端

- `已確認`：本地存檔 schema version 為 3，載入支援 v2／v3 並補入預設欄位。
- `已確認`：存檔包含資源、關卡、武將、編隊、裝備、任務、活動、商城與離線狀態；`persist()` 先寫 localStorage，再排入雲端同步。
- `缺少證據`：正式 Firebase、跨裝置衝突、原生 Google bridge、正式 Firestore 規則與實機重連尚未驗證。

## 目前品質判定

目前判定：`FAIL／不可發布`。

主要事實：攻擊圖集被隔離；兵器與敵人身分仍有視覺錯誤；編隊、戰法、裝備與副模式未形成足夠的玩家選擇；基準尺寸存在遮擋、面板被自動關閉、文字與表面錯誤；我方、普通敵人與 Boss 尚未完成 idle／move／attack／hit／death 的完整證據矩陣；正式平台帳號、政策與實機流程也未完成。
