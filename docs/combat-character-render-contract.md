# 戰鬥角色視覺契約 v2

這份契約是戰鬥畫面的人物、敵人、坐騎與武器共同規格。它和背包卡片、頭像、戰報 UI 分開；任何卡片資產不得直接當作戰鬥貼圖。

## 硬性規則

- 角色身體、敵人身體、Boss 與坐騎必須使用透明圖像資產。
- 武器必須使用 `combat-weapon-*-v2.webp`，不可使用帶卡片底框的 `equipment-weapon-*`。
- 戰鬥角色層不得用矩形繪製身體、手臂、腿或武器；載入未完成時留空，不退回方塊 placeholder。
- 攻擊 sprite sheet 只有在它具有完整方向、攻擊幀與角色生命週期契約時才能使用；目前只給我方攻擊狀態使用。
- 同一角色生命週期只能有一個身體層和一個武器層，禁止攻擊圖再疊一把外部武器。

## 資產與錨點

| 層 | 規格 | 錨點 | 使用時機 |
| --- | --- | --- | --- |
| combat body | 32×38 WebP | 腳底中心 | 待機、移動、攻擊、受擊、死亡 |
| combat weapon v2 | 64×64 WebP | `[32, 54]` 握點 | 非攻擊圖狀態的武器層 |
| mount | 48×32 WebP | 腳底中心 | 騎兵與 Boss |
| Boss body | 64×72 WebP | 腳底中心 | Boss 全生命週期 |
| attack sheet | 8 方向 × 5 幀，64px cell | 腳底中心 | 目前僅我方攻擊狀態 |

## 生命週期驗收

1. 待機：武器握點貼住手部，沒有黑框、浮空卡片或第二把武器。
2. 攻擊：身體、武器、特效方向一致；攻擊結束後恢復待機，不殘留攻擊姿勢。
3. 受擊：只出現短暫閃光與受擊位移，不覆蓋成矩形白塊。
4. 死亡：身體由原本的透明資產倒下淡出，不切回攻擊幀、不留下武器或血條。
5. 窄版 320×568 與標準 390×720 都必須維持上述錨點與可辨識度。

目前普通敵將若沒有同名 combat-body，使用既有透明名將身體的明確 alias；這是資產遷移層，不得再新增方塊式敵人 fallback。
