# 三國：群英再起 — 暫緩與待補清單

> 更新：2026-08-27。原則：本地可以完成的先做；需要專案持有人帳號、伺服器、金鑰或法務資料的項目不以假資料代替。

## 本輪已補上的本地功能

- 每日副本、體力上限與每 5 分鐘自然回復。
- 問天樓無盡模式、逐層戰力曲線與本地結算。
- 已通關關卡掃蕩與 1 / 2 / 4 倍戰鬥速度（第 5 關後開放 4 倍）。
- 陣營、義結、稱號、寶物與裝備精煉，全部接入本地存檔與戰鬥數值。
- 圖鑑、日務、行商、演武、問天樓、副本、限時活動、公告與頭像框快捷入口。
- UI 重複宣告清理、缺少 DOM hook 防護、離線翻倍按鈕與 smoke test 覆蓋。

## 本輪新增的本地功能

- 武將升星／突破、通用名將碎片、戰力成長與領取流程。
- 頭像框收藏、限時週活動、系統公告與本地版本檢查。
- 兵種克制（步兵→弓兵→騎兵→步兵）與敵軍目標優先級。
- 戰法升級、手動施放、結算傷害統計與章節天候渲染。


## 暫緩項目

### 需要外部服務或持有人資料

- 雲端存檔、帳號登入、真實排行榜、公會、好友、聊天與跨玩家分享：需要後端、身份驗證、資料庫、濫用防護與隱私政策。
- 正式 Google Play / App Store IAP：需要商店商品、服務帳號、收據驗證後端或 RevenueCat 專案；目前只保留不會誤發貨的原生橋接器。
- Android signed AAB、keystore、Play App Signing、internal/closed test：需要發布方自己的金鑰與 Play Console。
- 正式 AdMob、app-ads.txt、Data safety、隱私政策公開 URL、內容分級與客服信箱：需要發布方帳號與法務確認。

### 可在下一輪補，但目前不阻斷本地 MVP

- 多語言翻譯資源與語言切換：目前只有繁體中文，待確認各語言文案與字體規格。
- 真正音樂、環境音、武將語音與勝敗音效：目前使用 WebAudio 合成 fallback，待提供可授權音檔。
- 原生排程推播與通知渠道：目前只請求權限並保存狀態，待 Capacitor 原生通知插件與渠道設定。
- 更深的裝備掉落詞綴、限時裝備活動的完整經濟表：目前已有基礎掉落、精煉、限時週活動與升星／突破可玩循環，待補齊更深的詞綴資料。
- 客戶端防作弊只能做輸入與存檔健全性檢查；真正防刷與退款回收仍需伺服器。

## 待補順序

1. 發布方提供正式 application ID、AdMob / IAP 商品與隱私政策資料。
2. 建立後端帳號、存檔、排行榜與收據驗證，再接上目前保留的 adapter。
3. 提供授權音檔、翻譯表與商店截圖規格，補齊內容資產。
4. 完成 Android 實機與商店測試後，才把上架清單勾選為完成。
