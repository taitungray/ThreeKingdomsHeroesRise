## 2026-08-30 Layout Reset

- 戰鬥 HUD 改為固定兩列指揮條：主公／速度、關卡／波次；主線 chip 只佔指揮條安全區，不壓住敵軍生成區。
- 右欄固定 48px 觸控目標，最多四個快捷＋軍務清單；底部固定 58px 資源列＋78px 五頁籤。
- 日常任務改用 `badge → main → action` 語意 grid，進度、獎勵、狀態各有獨立欄位；360px 以下操作鈕改全寬下一列。
- `scripts/ui-function-smoke.js` 增加 390×720、320×568 的 HUD 幾何與任務列 bounding-box 檢查，並輸出固定尺寸截圖至 `artifacts/`。
- 軍務抽屜改為「外框固定、清單內部滾動」，與資源／底部導航保留安全距離；回歸測試會實際點擊 11 個抽屜入口並確認入口可到達最後一列。
- 戰場底圖改用交錯的大尺寸像素材質與低對比環境疊色，取消 96px 方格磁磚感；canvas 兩側留白改為同色鐵木基底，避免不同章節底圖突然切換。
- 戰鬥外框固定跟隨 390px 世界寬度；430px 寬的手機／WebView 會把多出的寬度留在 App 外側，Canvas 不再露出左右異質邊條。
- UI 改回手機優先的固定直式殼：390px authored viewport，桌面與觸控平板只保留外側 letterbox，不把面板展開成桌面管理台；武將／編隊名冊手機維持 2 欄，360px 以下降為 1 欄。
- 名冊頭像維持手機 48px 正方形 token；所有同類槽位仍由 avatar token 控制，不因桌面預覽放大而改變手機比例。
- 編隊兵種精研列維持紙卷底、14px 操作字與 12px 費用字；朱砂按鈕使用米金反白字，避免右側 CTA 低對比。
- 武將名冊排序固定以「出戰 → 已擁有 → 未相遇」為第一層級，再套用戰力／等級／兵種排序；玩家開啟名冊即可先看到目前陣容。
- 16 個面板在 390×720 與 320×568 各跑一輪：檢查水平溢出、面板逃逸、直排文字、按鈕裁切與 page error 均為零。
