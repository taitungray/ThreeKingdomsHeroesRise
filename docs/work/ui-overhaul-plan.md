# 三國：群英再起 UI 全面視覺重構與「去網頁感」升級規劃方案

針對使用者提出的核心訴求：
1. **不要用文字圖/CSS 線條圖，全面替換為專屬遊戲圖標資產**
2. **畫面極致精美，徹底消除「陽春、簡陋、像網頁做的」感覺，達到高品質商業手遊視覺水準**

---

## 一、現況深度診斷（為什麼看起來像「陽春網頁」？）

根據目前即時運行遊戲畫面的詳細檢視與截圖診斷，遊戲目前主要呈現出「網頁感/陽春感」的關鍵根源如下：

| 區域 | 目前陽春/網頁感現況 | 升級目標與重構方向 |
| :--- | :--- | :--- |
| **底部導航列** | 使用純 CSS `before/after` 旋轉 2px 線條硬拼（交叉線=刀、方塊圈=地圖），缺乏立體感與遊戲感 | 改為**暗金浮雕 + 玉石質感的 5 大專屬手遊導航圖標**（征戰令、名將盔、虎符陣、錦囊計、山河圖） |
| **右側快捷功能** | 圓形按鈕內用 CSS 邊框拼齒輪、信封、方塊，像網頁後台 icon | 改為**青銅/漆器精鑄戰術圖標**（設定、軍件、日務、行商、帥旗、問天等） |
| **頂部/底部資源列** | 銅錢、糧草、勾玉、魂石皆用 CSS 旋轉幾何圖形代打 | 改為**高光立體 3D 質感資源圖標**（赤金古幣、立體糧袋、碧璽翡翠、神魂玄晶） |
| **主公牌與頂部 HUD** | 平面灰色剪角卡片（`clip-path`）與純文字，缺乏分量 | 升級為**赤金鑲玉虎符主公牌**、立體琉璃經驗條、戰旗關卡標牌 |
| **面板與彈窗** | 泛黃平淡的泥土色背景（#cdbd94）配黑色平直線邊框，像網頁表格卡片 | 升級為**深黑赤金漆器 + 錦緞雲紋 + 四方神獸金屬角花 + 古典卷軸飾邊** |
| **按鈕體系** | 扁平漸層配 1px 內陰影，按壓僅位移 1px，無手遊厚重反饋 | 打造**厚重朱漆印綬鈕、青銅玄鐵鈕、金屬邊框光澤與 3D 凹陷動態** |
| **未解鎖/卡片狀態** | 灰底方塊顯示文字「尚未相遇、???」像資料庫缺漏 | 升級為**神秘名將剪影 + 鎖鏈封印紋章 + 戰力金色星階** |
| **開場/登入畫面** | 白色/米色網頁 Modal 置中，外觀如同一般網站 Google 登入表單 | 升級為**大氣磅礴的三國英雄開局主視覺、古風登入介面與沉浸式開場** |

## 二、全面升級方案：四階段實施路徑

### 第一階段：專屬 UI 圖標資產全面繪製（徹底替換 CSS/文字圖）

製作高解析度、風格統一的三國像素／厚塗古風 UI 資產（輸出至 `assets/icons/`）：

1. **五大核心導航圖標 (`assets/icons/nav-*.webp`)**：
   - `nav-battle.webp`：赤金雙龍交錯古劍與戰旗（征戰）
   - `nav-heroes.webp`：金甲神將頭盔與背光（武將）
   - `nav-formation.webp`：九宮八卦陣圖與青銅虎符（編隊）
   - `nav-tactics.webp`：諸葛錦囊與太極密卷（戰法）
   - `nav-campaign.webp`：羊皮戰略地圖與九州山河（戰役）

2. **八大軍務快捷圖標 (`assets/icons/rail-*.webp`)**：
   - `rail-settings.webp`：青銅八卦機關盤（設定）
   - `rail-mail.webp`：漆金火漆密信竹簡（軍件）
   - `rail-daily.webp`：點將台軍令日曆（日務）
   - `rail-shop.webp`：聚寶盆金玉商行（行商）
   - `rail-events.webp`：赤炎戰旗（活動）
   - `rail-tower.webp`：九重問天摘星樓（問天）
   - `rail-rank.webp`：三足金鼎霸主榜（排行）
   - `rail-achievement.webp`：金鑲玉將軍勳章（成就）

3. **四大資源與消耗品圖標 (`assets/icons/res-*.webp`)**：
   - `res-coin.webp`：外圓內方開元通寶金幣（銅錢）
   - `res-food.webp`：錦袋軍糧捆草（糧草）
   - `res-jade.webp`：溫潤剔透雙龍碧玉佩（勾玉）
   - `res-shard.webp`：流光溢彩武魂神晶（將魂）
   - `res-exp.webp`：紫金太極玄天丹（經驗）

4. **四大裝備插槽底圖與角標 (`assets/icons/slot-*.webp`)**：
   - 神兵槽（金刃底印）、寶甲槽（龍鱗甲印）、名駒槽（赤兔蹄印）、玉佩槽（神符印）

---

### 第二階段：戰場 HUD 與主畫面沉浸式「去網頁化」

1. **主公資訊名牌（Top Lord HUD）**：
   - 移除平淡 clip-path 灰卡，改用**金屬雕花邊框 + 琉璃晶透經驗條 + 立體將星官職牌**。
   - 點擊主公名牌時彈出的資訊框增加金絲刺繡錦緞底紋。
2. **戰場波次與首領戰資訊（Battle Meta）**：
   - 關卡進度改為立體「懸掛木雕軍令旗」造型。
   - 戰鬥加速按鈕（×1 / ×2）改為青銅齒輪加急旋風按鈕。
3. **挑戰首領按鈕（Boss Trigger Button）**：
   - 滿波次可挑戰時，加入**血炎燃燒光暈呼吸動效**與金角衝天戰印，凸顯大招式的手遊點擊誘惑力。
4. **底部導航欄（Bottom Navigation Bar）**：
   - 採用**黑檀木漆金底座 + 精美金屬分割柱**。
   - 選中狀態時，圖標上方綻放赤金光圈與浮雕上移反饋，完全比照商業級手遊標準。

---

### 第三階段：面板系統（Panels）與彈窗（Modals）手遊化精修

1. **彈窗外框與材質**：
   - 面板邊框替換為古典**四角鎏金回紋角花**，底色改為帶有暗紋浮雕的「皇家深宮漆器 + 卷軸米宣」雙層結構。
   - 標題欄改為「御賜金匾/赤金橫額」造型，兩側飾以祥雲龍紋。
2. **分頁標籤（Tabs）**：
   - 移除生硬方塊按鈕，改為「古風卷軸籤條」或「玉符扣合」外觀，切換時有溫潤的亮光滑動反饋。
3. **武將名冊（Roster List）與編隊介面**：
   - **已擁有武將**：精美金框/紫框、星級金星亮起、兵種（步/騎/弓/謀）立體徽章。
   - **未解鎖武將**：精緻暗影剪影 + 封印符咒與解鎖關卡指引，提升收集期待感。
   - **編隊九宮格**：改為漢白玉／青石演武台地磚質感，空槽位顯示古風「候令」八卦印記。
4. **戰鬥結算報告（Settlement Modal）**：
   - 勝利時由上方重重蓋下「大捷／全勝」朱紅御璽印章，伴隨金光火花。
   - 戰利品掉落使用獨立金色木盤托底，資源圖標整齊發光排列。

---

### 第四階段：開場登入、字型與氛圍微動態

1. **開場與登入（Title Screen）**：
   - 移除置中白卡表單，改為全屏壯麗古戰場群英插畫為底。
   - 遊戲標題「三國：群英再起」使用燙金立體字特效。
   - 「進入遊戲／訪客試玩／Google 帳號登入」做成雕龍刻鳳的金屬令牌按鈕。
2. **字體與排版（Typography）**：
   - 標題全面採用典雅的行楷/魏碑/古風 serif 渲染，數值採用清晰有質感的等寬金屬數字，徹底告別預設系統黑體帶來的陽春感。
3. **微動態與音畫回饋（Micro-animations）**：
   - 面板開啟支援卷軸展開/淡入緩動動效。
   - 按鈕具備「3D 深度點擊壓縮感」與「金屬微光掃過（Sheen effect）」。

## 三、驗證與驗收標準

1. **自動化驗證**：
   - `node --check` 確保所有 JS/CSS 語法無誤。
   - `npm test` 冒煙測試全數通過。
   - `npm run test:docs` 與 `npm run test:combat-assets` 通過。
2. **視覺 QA 驗收**：
   - 透過瀏覽器視覺檢查工具在手機螢幕尺寸（390×844 等）檢驗整體畫面：
     - 是否已零 CSS 刻線圖標（全為高清遊戲圖標）？
     - 整體色彩層次是否具備深沉、厚重、華麗的三國大作氛圍？
     - 是否完全消除網頁表格、網頁卡片的簡陋感？
