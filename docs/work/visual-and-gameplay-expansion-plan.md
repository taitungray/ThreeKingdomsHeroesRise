# 戰鬥演出視覺化與新玩法模式擴充實作計畫

狀態：PLANNING。本計畫針對「二、戰鬥演出與資訊視覺化」與「三、玩法模式與長線挑戰」進行系統、數值、介面與渲染的完整整合設計。

---

## 系統架構與功能亮點

### 1. 戰後全維度數據統計儀表板 (Battle Analytics Dashboard)
- **多維度戰鬥指標**：除了現有輸出 (DPS)，全面追蹤並記錄每位武將的 **「傷害輸出」**、**「承受傷害 (坦克值)」**、**「治療輔助」** 與 **「擊殺數 (Kills)」**。
- **直觀可視化圖表**：以勢力色動態長條圖、百分比、MVP 金色勳章與數值格式化展示。
- **隨時回看**：在結算彈窗與戰役面板中提供「戰況詳報」隨時調閱上一場或當前戰役數據。

### 2. 名將宿命合體奧義 (Synergy Combo Ultimates)
- **經典三國宿命羈絆**：
  - **桃園三結義**（劉備 + 關羽 + 張飛）：觸發【義薄雲天】，全隊獲得護盾並對全場敵人造成巨額雷霆打擊。
  - **臥龍鳳雛**（諸葛亮 + 龐統）：觸發【神機妙算】，全場大火 + 狂暴增傷。
  - **絕世霸王**（呂布 + 貂蟬）：觸發【英雄美人】，全場魅惑並施加連續方天狂斬。
  - **江東雙璧**（周瑜 + 孫策/小喬）：觸發【赤壁燎原】，全體灼燒並提升我方急速。
- **專屬雙人/三人 Cut-in 演出**：結合像素動畫與全屏特寫光效。

### 3. 過關斬將／血量繼承遠征 (Expedition Trial / 15 關挑戰)
- **血量繼承機制**：每位武將戰鬥後的剩餘血量與死亡狀態帶入下一關，無法自動回滿，真正考驗 50 位名將的陣容調度與板凳深度。
- **守將據點與寶箱**：共 15 個關卡據點，每 3 關設有菁英據點與豐厚通關寶箱。
- **遠征幣與專屬商店**：產出專屬遠征幣，可兌換稀有 SSR 碎片與神兵突破石；每日設有 1 次重置整軍機制。

### 4. 絲路商隊／名將委派派遣 (Caravan Dispatch)
- **放置委派玩法**：開放多條經典商道（如：洛陽神兵道、荊襄糧運、巴蜀玉道、西域絲路奇珍）。
- **條件與大成功加成**：派遣符合特定兵種（如騎兵）或特定勢力（如蜀漢名將）的閒置武將，可提高大成功機率，產出 1.5~2 倍獎勵。
- **掛機自動累積**：2h / 4h / 8h 任務，隨時間推進，上線一鍵領取海量資源與名將碎片。

## 驗證計畫

### 1. 語法與單元測試
- 執行所有相關 JS 檔案的 `node --check`
- 執行 `npm test` 確認自動化測試全部通過。

### 2. 功能與數值驗證
- **數據儀表板**：模擬戰鬥後驗證輸出 + 承傷 + 治療數值總和與戰鬥過程完全吻合，MVP 標記準確。
- **宿命合體技**：配置劉關張或諸葛龐統，驗證怒氣滿時觸發合體技特寫與全屏清場。
- **過關斬將**：進行連續 3 關戰鬥，驗證血量繼承扣減，陣亡名將在後續關卡正確判定無法出戰。
- **絲路商隊**：派遣 2 名武將出發，模擬時間推移後成功領取獎勵並正確入庫。
- **文件驗證**：執行 `npm run test:docs` 確保無任何文件衝突。
