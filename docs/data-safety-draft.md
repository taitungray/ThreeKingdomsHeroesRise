# Data safety 草稿（發布前重新確認）

目前 Web prototype 只把遊戲進度保存在裝置 localStorage，沒有帳號、雲端存檔或分析服務。若維持此狀態，商店表單應以實際 Google Play SDK 掃描結果為準。

加入 AdMob 後，必須依 AdMob SDK 的實際資料處理更新：

- 廣告請求、裝置識別、診斷或防詐資料可能由 Google 處理。
- 必須說明資料是否用於廣告、分析、個人化與應用程式功能。
- 若日後加入 Firebase 登入或雲端存檔，需另外說明帳號、遊戲進度、刪除流程與保存期限。
- 不可勾選「可要求刪除」除非應用程式真的提供可用的刪除流程。

此文件是內部草稿，不可直接當成 Play 表單或隱私政策。
