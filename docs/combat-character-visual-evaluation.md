## 二、四大畫面致命問題詳解

### 1. 歷史名將「有名無實」（Enemy Generals lack Visuals）
*   **問題**：在戰鬥頂部 HUD、Enemy Preview 都有張角、董卓、呂布的頭像與稱號，但生成在戰場上時，代碼全用 `bandit`、`brute`、`cavalry` 通用小兵模型！
*   **影響**：玩家打 Boss 時感覺只是在打「一隻放大版的普通黃巾賊」，嚴重缺乏史詩感與擊殺名將的快感。

### 2. 46 名武將共用「大眾臉」與通用技能
*   **問題**：雖然資料庫有 50 名武將，但 `game-render.js` 裡的手繪邏輯只有前 12 位（`liubei`, `guanyu`, `zhangfei`, `zhaoyun`, `huangzhong`, `sunshang`, `caocao`, `xiahoudun`, `zhugeliang`, `diaochan`, `lubu`）。
*   **影響**：新解鎖的武將在戰場上長得跟初始武將一模一樣（僅換披風顏色），降低了收集欲望。

### 3. 戰鬥缺乏「受擊反饋」與「大招特寫」
*   **問題**：
    *   攻擊打中小兵時，只有單純數字冒出，沒有受擊白閃（White Flash）或向後退步的受擊硬直（Stun）。
    *   施放大招時，沒有「全屏微暗（Dim Screen）」或「金色聚焦光圈」，在混戰中容易忽略是誰放了技能。

### 4. 戰場層次與地面陰影過於扁平
*   **問題**：角色腳底只有單純的半透明橢圓陰影（`ctx.ellipse`），在坐騎跳躍或跑步時，陰影不會隨高度縮放，缺乏空間立體感。

## 三、具體改造與強化方案

### 方案 1：歷史敵將專屬造型庫（Boss Visual Overhaul）
為 7 大核心 Boss（張角、董卓、呂布、袁紹、孟獲、祝融、司馬懿）獨立配置 Canvas 繪製特徵：
- **張角**：黃巾道袍 + 手持九節杖 + 腳底旋轉黃色符文法陣。
- **董卓**：極其魁梧的黑金重甲 + 巨型砍刀 + 兇殘橫肉輪廓。
- **呂布**：標誌性雙翎雉雞翎（插在頭頂發光顫動）+ 方天畫戟燃燒紅焰。
- **孟獲**：藤甲巨漢 + 雙手石斧 + 騎乘戰象（Elephant）。

### 方案 2：角色大招演出升級（Ultimate Cinematic）
- **施法瞬間（0.25s）**：
  - 遊戲時間短暫微慢速（Slow-motion）。
  - 背景壓暗 30%，施法武將發出高亮金色邊緣光（Rim Light）。
  - 武將頭頂彈出極具三國風的書法字招式名（如「青龍偃月」）。

### 方案 3：精細化打擊反饋（Enhanced Combat Reactions）
```
攻擊命中 -> 目標瞬間全白 0.04s -> 身體產生 squashX: 0.15 擠壓 -> 拋物線彈出傷害數字 -> 腳底留下短暫塵土
```

### 方案 4：狀態效果（Buff/Debuff）視覺標籤
在角色頭頂或腳下加入微型動態圖示：
- **灼燒/火攻**：腳底燃燒微型火焰粒子。
- **眩暈/震懾**：頭頂旋轉小金星。
- **狂暴/攻擊提升**：全身散發微弱上升紅氣。
- **護盾**：身體外圍浮現淡藍色半透明光盾。
