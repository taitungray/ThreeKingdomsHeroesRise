## 封存規則

- 不在封存文件追加新的「已完成」段落，也不從其中恢復 active checklist。
- 仍有效的規則要移入 `standards/`；目前事實移入 `specs/`；未完成行動移入 `work/`；實際缺陷移入 `issues/`。
- 舊百分比、評分、工期、費率與外部政策只代表當時觀察，不可直接用於目前決策。
- 若封存內容與現況衝突，以 [目前遊戲規格](../specs/current-game-spec.md) 為準。
