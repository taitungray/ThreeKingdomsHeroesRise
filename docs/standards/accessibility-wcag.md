# 無障礙與行動裝置規範

狀態：MANDATORY STANDARD。產品以 WCAG 2.1 AA 為目標，但只有完成瀏覽器與實機證據後才能宣稱通過。未完成工作記在 [目前工作清單](../work/active-backlog.md)，不在本規範追蹤進度。

## 語意與非文字內容

- `html` 使用 `zh-Hant`；每個按鈕、圖示按鈕、資源與狀態都有可理解的繁體中文名稱。
- 裝飾圖層使用 `aria-hidden="true"`；資訊圖示由文字、`aria-label` 或父容器提供語意。
- 選取、展開、按下、鎖定、停用、載入、完成與已領取同步適合的 ARIA／HTML 狀態。
- 不用顏色作為唯一提示；至少再提供文字、圖形、位置或形狀差異。
- Canvas 需有整體標籤；波次、敵人數、Boss、勝敗與可操作技能另由 DOM／live region 提供文字。
- 高頻傷害數字不逐筆朗讀，避免讀屏被洗版。

## 鍵盤、焦點與彈窗

- 所有互動控制項可用 Tab 到達並以 Enter／Space 操作；`focus-visible` 外框不可移除。
- 開啟面板或 modal 後，焦點移至標題或第一個合理控制項，Tab／Shift+Tab 留在最上層 modal。
- Escape 關閉最上層可關閉介面；關閉後焦點回到原觸發按鈕。
- 隱藏介面不得留在 tab order；disabled 要有可讀原因，不只降低 opacity。
- 觸控、滑鼠與鍵盤不可讓同一獎勵或操作重複觸發。

## 可讀性與對比

- 正文與必要說明至少 14px；主要按鈕與重要數值至少 16px；必要資訊不得小於 12px。
- 一般文字對比至少 4.5:1，大字至少 3:1；焦點、元件邊界與非文字狀態至少 3:1。
- 戰場上的文字使用實色底、描邊或足夠遮罩，不能只靠陰影勉強辨識。
- 200% 縮放時仍可操作，必要資訊不裁切、不重疊、不要求整頁水平捲動。

## 觸控、方向與安全區

- 主要互動控制項最小 44×44 CSS px，並保留避免誤觸的間距。
- 不依賴 hover、雙擊或精準拖曳；拖曳功能提供點選式替代方案。
- 使用 safe area；390×720、430×932、320×568 與短高橫向都有可理解降級。
- 直式鎖定時顯示旋轉提示，不讓半截戰鬥 UI 留在畫面。

## 動畫、震動與音訊

- 尊重 `prefers-reduced-motion`：關閉裝飾粒子、常駐脈動、全畫面震動與不必要過場，保留必要結果。
- 不呼叫 `navigator.vibrate`；觸覺回饋不作為必要資訊來源。
- 閃爍不超過每秒三次；快速白閃、紅閃與全畫面 flash 必須有 reduced-effects 降級。
- 音效與音樂可獨立關閉；關鍵狀態不能只靠聲音傳達。

## 驗收

1. 鍵盤走完登入、戰鬥、五個底欄、右側軍務、面板與結算。
2. 檢查每個 dialog 的初始焦點、focus trap、Escape 與焦點返回。
3. 使用 Accessibility tree 檢查名稱、角色、狀態與 live region。
4. 量測正文、次要文字、按鈕、焦點與 disabled 對比並保留數值。
5. 測試 200% 縮放、基準尺寸與 `prefers-reduced-motion: reduce`。
6. 發布前至少執行 Android TalkBack；iOS／PWA 若列入發布範圍，另做 VoiceOver。

測試方法與結果判定依 [QA 測試矩陣](../qa/qa-test-matrix.md)；未執行項目必須明列，不得以存在 ARIA 屬性代替驗收。
