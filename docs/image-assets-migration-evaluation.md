# 三國：群英再起 — 「純代碼繪製 vs 點陣圖片資產 (Sprites/PNG)」深度架構評估

> 本文件專門分析：**如果將目前的「純代碼/CSS 繪製」改成「真正的點陣圖片素材 (PNG / WebP / SpriteSheets)」**，會帶來哪些利弊、視覺提升幅度、技術代價與最佳混用架構。

---

## 一、直接結論（Executive Summary）

> **結論：非常值得改！但建議採用「分層混合架構（Hybrid Architecture）」**。
>
> 1. **頭像、裝備、UI 圖示、字體、背景**：👉 **強烈建議直接改用圖片/WebP 資產**！
>    - 視覺品質立即從「原型 Demo 感」躍升至「商業級手遊大作」。
>    - 解決 CSS 繪製在手機上的渲染效能消耗與長度高達 800+ 行的代碼維護地獄。
> 2. **戰鬥角色與紙娃娃換裝**：👉 **建議改為「像素 Sprite Sheet 點陣圖格」**，但保留 Canvas 骨架座標調度。
>    - 既能維持「即時換裝、任意換武器/坐騎」的超高自由度，又能享受「真正手繪像素」的精緻光影與細節。

## 二、「純代碼手繪」vs「圖片素材」全方位對比

| 評估維度 | 目前方案：純代碼 / Canvas 手繪 / CSS | 改用圖片方案：PNG / WebP / SpriteSheet | 評估建議 |
|---|---|---|---|
| **視覺上限 (Art Quality)** | ⚠️ **低～中**<br>受限於程式幾何色塊，無法做出細膩的眼部表情、金屬光澤、破損紋理與柔和陰影。 | 🌟 **極高（商業級）**<br>可使用 Aseprite / Photoshop 繪製 4 階色階、動態眼神光、水墨筆觸、金屬質感。 | 圖片徹底碾壓純代碼 |
| **產能與擴充 (Scalability)** | ❌ **極痛苦**<br>每加一個新武將或武器，需要寫 50 行 `ctx.fillRect` 或 CSS `clip-path`，調座標極度費時。 | ✅ **極高效**<br>美術直接匯出 48×48 PNG 圖檔，代碼只需讀取檔名（如 `guanyu.png`），完全不需手動寫幾何代碼。 | 圖片更易擴充 50~100 名將 |
| **效能與記憶體 (Performance)** | ⚠️ **CPU 算力負擔重**<br>每幀用 Canvas 重新計算數百個幾何矩形，高刷新率手機發熱；CSS 超長選擇器重繪慢。 | ✅ **GPU 渲染極快**<br>`drawImage` 或 CSS `background-image` 由 GPU 硬體加速，每幀消耗 < 0.1ms。 | 圖片渲染更省電更順暢 |
| **包裝體積與載入 (File Size)** | ✅ **極小（約 200KB）**<br>純文字檔案，完全不需要下載圖片。 | ⚠️ **增加至 3MB ~ 8MB**<br>放置遊戲像素圖極小，全部打包壓縮為 WebP 後通常僅 2~4MB，在現代 5G/Wi-Fi 下 0.5 秒內載入完成。 | 現代環境下體積完全不是問題 |
| **紙娃娃換裝 (Paper-Doll)** | ✅ **天然支援**<br>部位隨意疊加座標。 | ⚠️ **需規範錨點 (Anchor Points)**<br>身體、武器、坐騎圖檔需固定中心點與層級（Z-Index）。 | 建立規範即可完美解決 |

## 三、各模組具體改造收益評估

### 1. 角色大頭貼（Avatar Portraits）— 【收益最大 ⭐⭐⭐⭐⭐】
*   **現狀**：`styles.css` 佔用了近 400 行寫 `.avatar-liubei`, `.avatar-guanyu` 的 `clip-path` 與漸變。
*   **改為 64×64 PNG/WebP**：
    *   `styles.css` 大幅瘦身 50%。
    *   頭像可呈現出精緻鬍鬚毛髮、金屬頭盔反光、眼神光。
    *   後續新增 38 名武將只需丟圖片進 `assets/avatars/`，零代碼負擔！

### 2. 武器裝備與道具圖示（Equipment Icons）— 【收益巨大 ⭐⭐⭐⭐⭐】
*   **現狀**：純幾何色塊，沒有金屬反光與品質框。
*   **改為 48×48 PNG 圖示**：
    *   青龍刀可見龍紋雕刻與青綠色淬火刃光。
    *   方天畫戟帶有金屬倒鉤與飄動紅纓。
    *   各品質外框（白/綠/藍/紫/橙）具備真實金屬與寶石鑲嵌質感。

### 3. UI 材質與背景（UI Surfaces & Backgrounds）— 【收益極大 ⭐⭐⭐⭐】
*   **現狀**：純色漸變模擬宣紙與木紋，偏塑料感。
*   **改為九宮格紋理（9-Slice / Texture Tiles）**：
    *   彈窗底圖改用一張 10KB 的無縫宣紙古卷紋理。
    *   按鈕使用真古銅/朱砂印泥質感底圖。
    *   戰場地圖背景改用像素繪製的古戰場地圖塊（草地、碎石、水波、泥土）。

### 4. 戰鬥角色動作（Combat Sprites）— 【高性價比折衷方案 ⭐⭐⭐⭐】
*   **拆件式像素素材（Modular Pixel Parts）**：
    *   不繪製整隻死板的動畫，而是將武將拆為：`頭部 (Head)`、`軀幹 (Body)`、`手臂武器 (Arm/Weapon)`、`坐騎 (Mount)`。
    *   Canvas 依然用代碼控制呼吸、揮砍與移動晃動，但繪製時是呼叫 `ctx.drawImage(headImg, x, y)`。
    *   **完美兼得**「精緻像素畫風」與「紙娃娃自由換裝換坐騎」！
