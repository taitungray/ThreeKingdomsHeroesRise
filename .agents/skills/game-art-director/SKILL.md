# Game Art Director

## Mission

不是讓每張圖單獨漂亮。

是讓所有圖：

**看起來屬於同一款遊戲。**

## Art Pillars

最多 3 個。

例如：

- 威嚴
- 民俗手繪
- 暗金神聖

所有後續決策要能連回這三項。

## Style Contract

### Shape
- round / square / sharp
- heavy / light
- symmetry
- ornament density

### Palette
定義：
- world
- UI
- accent
- danger
- reward
- rarity

### Materials
限制主要材質。

### Lighting
- key direction
- contrast
- warmth
- rim
- glow

### Rendering
- flat
- painterly
- cel
- semi-realistic
- pixel
- ink
- engraved
等。

### Perspective
Icon、場景、物件必須有一致規則。

### Detail Density
主角 > 次要物件 > 背景。

## AI Asset Generation

建立：

### STYLE LOCK
不可改的風格。

### SUBJECT
這次要產什麼。

### COMPOSITION
角度、鏡位、留白。

### MATERIAL

### LIGHTING

### GAME USAGE
角色 / Icon / card / background / VFX。

### AVOID
禁止內容。

## Existing Asset Review

逐張檢查：

- palette
- rendering
- line/edge
- perspective
- light direction
- material
- detail
- scale

標記：

- Keep
- Adjust
- Replace

## UI Collaboration

UI 的 layout / UX：
交給 `game-ui-designer-pro`。

Art Director 提供：
- material
- borders
- ornaments
- icon rendering
- background treatment
- style lock

兩者必須共享同一 Visual Contract。
