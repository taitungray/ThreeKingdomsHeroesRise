# Game UI Review Checklist

## 3 Seconds
- [ ] 知道玩家要做什麼
- [ ] 知道主要操作
- [ ] 知道最重要資訊
- [ ] 背景不搶焦點

## Hierarchy
- [ ] Primary / Secondary / Tertiary 清楚
- [ ] CTA 不超過必要數量
- [ ] Meta UI 不搶 Gameplay

## Touch
- [ ] 常用按鈕好按
- [ ] 不靠太邊
- [ ] 不依賴 hover
- [ ] Disabled 不可觸發
- [ ] Safe area OK

## Visual
- [ ] 邊框規則一致
- [ ] 陰影方向一致
- [ ] Icon 風格一致
- [ ] Glow 有限制
- [ ] 字體層級一致
- [ ] 材質一致

## Game Feel
- [ ] Press 有 feedback
- [ ] Reward 有 feedback
- [ ] Danger 清楚
- [ ] Cooldown / State 可讀
- [ ] 不存在太多常駐動效

## Responsive
- [ ] 常見 16:9
- [ ] 超寬
- [ ] 高螢幕
- [ ] Resize
- [ ] Orientation
