# Layout Map Template

用區塊先規劃，不先寫 CSS。

```text
┌────────────────────────────────────┐
│ STATUS / RESOURCE                   │
├───────────────┬────────────────────┤
│               │                    │
│   GAMEPLAY    │     GAMEPLAY       │
│               │                    │
│               │                    │
├───────────────┴───────────────┬────┤
│ contextual info               │CTA │
└───────────────────────────────┴────┘
```

每區標記：

- priority
- anchor
- can-overlap-gameplay?
- fixed/flexible
- hidden-in-combat?
- touch area
